Piper's current runtime is GPL, unlike the earlier MIT implementation. This package does not claim an all-MIT dependency stack. Preserve runtime and individual model notices before publication.

Qwen3-8B is used only through the Transformers library (Apache-2.0, listed above) with its own tokenizer and chat template; no Qwen3 file, fine-tune or conversion is included here or modified by KevFLIX. The optional setting translation_quantization "int8" quantizes the decoder linears to weight-only INT8 in memory while the supplied bf16 safetensors are loaded (KevFLIX's own pure-PyTorch code, relay/language.py: symmetric per-output-row scales, no third-party quantization library); no quantized weight file is written, shipped or redistributed, and the Apache-2.0 notices above apply to the weights unchanged. Keep the Apache-2.0 LICENSE file that ships in the Qwen3-8B folder, and the upstream model card, with the weights you supply. M2M100 remains the default translator; Qwen3-8B is used only when the settings say translation_engine "qwen3".

Whisper: the speech recognizer is faster-whisper (SYSTRAN, MIT) running the Systran/faster-whisper-small CTranslate2 conversion of OpenAI's Whisper (MIT). KevFLIX uses these names unchanged and claims no Whisper training or modification.


X-Voice weights (XRXRX/X-Voice) are licensed CC-BY-NC-4.0, which forbids commercial use. KevFLIX does not ship them;
anyone who provisions them must respect that term for the audio they generate. The X-Translator and X-Voice source under
relay/vendor/xtranslator is MIT as declared by its upstream READMEs; the pinned upstream trees contain no standalone
LICENSE file, so KevFLIX reproduces the READMEs, pyproject metadata and notices instead of inventing a copyright line.
KevFLIX's own changes to that source are the numbered patches under relay/vendor/xtranslator/patches and are recorded in
PROVENANCE.json.

VoxCPM2 and audio.cpp: the Vox voice model and the native runtime are provisioned from folders the user supplies and are
verified against the sha256 values pinned in actor-tts/runtime-adapter/approved.py. They are not part of this repository
or of the installer. audio.cpp is Apache-2.0 (Copyright 2026 ShugoAI LLC). The runtime named "v0.9.1 with PCM callback ABI"
includes a local modification; see the provenance note above before redistributing a binary.

eSpeak NG is GPL-3.0-or-later and is built on the user's PC by the optional X-Translator setup; it is not shipped. Piper
(GPL-3.0, listed above) is likewise a separately installed dependency. This package therefore does not claim an
all-permissive dependency stack.

The TV player (tv/app/player.js) embeds hls.js 1.7.3 (Apache-2.0) and regenerator-runtime (MIT); their license notices are
kept in the file's header comments.

The Audio Spectrogram Transformer is used only through Transformers with its own feature extractor; KevFLIX contains no AST file. Its labels are never shown to the viewer: they only decide that a stretch of original vocals is singing, chanting or another non-speech sound that stays as it is.
