# TV controls

KevFLIX uses a compact TV interface: Home, Movies, Search and Settings.
Movie cards open a details page with Play/Resume. Back returns to the previous
page without requiring a mouse.

## Pairing

The pairing screen has an on-screen number keypad. Use the remote's arrows to
highlight a digit, then press OK. After six digits, focus moves to Pair TV.
Delete and Clear are also on-screen buttons. A physical numeric remote is not
required, and the native TV keyboard is not used for pairing.

## Browsing

- Arrows move the visible focus highlight.
- OK selects a card, button or option.
- Back closes the current option menu or returns from movie details.
- Search opens text entry only when selected. Done/Enter returns focus to Search.
- Settings use button-based choices instead of native browser dropdowns.

## Playback

- OK or an arrow brings up the playback overlay when it is hidden.
- Play/Pause controls playback directly.
- Select the timeline and use Left/Right to seek in ten-second steps.
- Back closes an option panel, then hides the overlay; a further Back returns
  to the movie page.

These controls are intended to follow familiar TV-player conventions. Exact
behavior and layout still need acceptance on the target television. Playback
and AI processing remain blocked when the worker uses setup-only mode.
